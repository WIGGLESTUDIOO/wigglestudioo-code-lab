## 🎀 What is this?

This is the code library for my YouTube channel, **WiggleStudioo**. Every project from my videos and Shorts is here, so you can play with it, copy it, and make it your own. No experience needed. If you can copy and paste, you can build this.

## 🧁 What's inside

| Section | What you get |
|---|---|
| 🎬 **Long video code** | Full build-from-scratch projects: portfolio website, login page, 5 cute mini games, bakery website, love letter that types itself, photo booth and more |
| 📱 **Shorts code** | Quick little pieces from my Shorts: typing effect, scroll progress bar, accordion, copy button and more |
| 🐍 **Python** | Fun Python projects and experiments |

Every project has a live demo, a one-click copy button, and a download.

## 🚀 How to use the code

1. Open the [Code Lab](https://wigglestudioo.github.io/wigglestudioo-code-lab/).
2. Pick a project and press **Copy code**, or **Download** the zip.
3. Unzip it, then open `index.html` in your browser. That's it!

Tip: a project that uses the camera (like the Photo Booth) needs `https` or `localhost`, and you have to click Allow.

## 📁 Folder structure

```
wigglestudioo-code-lab/
├── index.html        the Code Lab page
├── style.css         the cute pink styling
├── script.js         the tiles, rows and filters
├── data.js           the list of all projects
├── build.py          adds new projects to the list
├── favicon.svg       the tab icon
├── demos/            one live demo page per project
├── downloads/        the zip for each long video
└── img/              screenshots used on the cards
```
